# TOGU — Roadmap

## MVP — v1
Autenticação, calendário, eventos, Soft Hold, usuários, amigos, Circles, disponibilidade, solicitações (enviar/aceitar/negar/reagendar), Priority Engine, notificações, web responsiva, mobile base.

## v1.1
Integração Google Calendar, Outlook, Smart Slots, Polls, Buffers, Quick Add (linguagem natural).

## v1.2
Explore, eventos próximos, lugares, convites para eventos.

## v1.3
Assistente inteligente de agenda, Planejar Rolê, sugestões sociais.

## v2
Grupos, comunidades, organizações, recursos premium (Business), ecossistema de integrações mais amplo.

## Squads envolvidos por fase
Ver `docs/adr/` e seção de squads no `README.md` — cada epic do roadmap é decomposto em Feature → Use Case → Implementation → Tests → Documentation → QA (regra de desenvolvimento incremental).
